# Plugin_QGIS_calcul_isochrones
Proposer un plugin QGIS permettant de faire appel au service de calculs d'isochrones de la [Géoplateforme IGN]([url](https://cartes.gouv.fr/aide/fr/guides-utilisateur/utiliser-les-services-de-la-geoplateforme/calcul-isochrone-isodistance/)). Possibilité de paramétrer la requête (url : https://data.geopf.fr/navigation/getcapabilities) avec toutes les possibilités offertes par le service, et afficher la réponse dans l'interface cartographique.
